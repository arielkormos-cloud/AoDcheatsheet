Shooting & Defence

Current Kill Team shooting sequence • tap highlighted terms for rule details

🎯 Shoot action

  1. Select a ranged weapon. Check any Range x or other weapon restrictions.
  2. Select a valid target. Check Visible, Valid Target, Cover, Control Range and Obscured.
  3. Roll attack dice. Roll the weapon's Atk dice; results meeting Hit are successes. Check Accurate x, Balanced, Lethal x+, Severe, etc.
  4. Defender rolls defence dice. Normally 3 dice, modified by rules such as Piercing x or Piercing Crits x.
  5. Resolve defence dice. The defender uses successful saves to block successful attack dice.
  6. Resolve remaining attack dice. Unblocked normal successes inflict Normal Dmg; unblocked critical successes inflict Critical Dmg.

🛡️ Defending against shooting

  1. Collect defence dice. Start with 3 unless a rule changes this. Piercing is the common modifier.
  2. Retain cover save if allowed. If the target is in Cover, one defence die can normally be retained as a normal success without rolling. Saturate prevents this.
  3. Roll remaining dice. Results meeting the operative's Save are successful. A 6 is critical; a 1 fails.
  4. Block attack successes. Normal save blocks a normal hit. Critical save blocks a normal or critical hit. Two normal saves can block one critical hit.
  5. Take damage. Only unblocked attack successes inflict weapon damage.
